# Security policy

## Supported versions

Tracepress is pre-1.0 and does not yet publish supported release lines. Security fixes currently
target the latest commit on the default branch. This policy must be updated when the first supported
release is published.

## Reporting a vulnerability

Do not disclose credentials, prompt or response content, command output, private paths, or exploit
details in a public issue.

GitHub Private Vulnerability Reporting is not currently enabled for this repository. Until it is
enabled, open a public issue containing only the sentence “Private security contact requested” and
no vulnerability details, reproduction steps, logs, or attachments. A maintainer can then establish
a private channel. Maintainers should enable GitHub Private Vulnerability Reporting before the first
public release and replace this fallback with the repository's private report link.

Include in the eventual private report:

- the affected revision and platform;
- impact and prerequisites;
- minimal reproduction steps using synthetic data;
- whether credentials or private content may have been exposed;
- any proposed mitigation.

Please allow maintainers time to reproduce and coordinate a fix before public disclosure. This file
does not promise a response or remediation deadline while the project has no supported release.
